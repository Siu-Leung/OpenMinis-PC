# OpenMinis-PC v1.13.0.29 开发日志

日期：2026-09-05  
内部版本：`1.13.29`  
对外版本：`v1.13.0.29`  
产品：OpenMinis Windows 体验版

## 范围

修复会话列表时间契约、持久化一致性和模型组设置保存参数，使 Windows 实现接近官方移动端稳定 createdAt/updatedAt 与唯一 session ID 的原则。

## 官方参考

- iOS：`ChatSession.createdAt` / `updatedAt`、`ChatStore.listSessions()`
- iOS：会话列表按 `updatedAt` 排序，session ID 作为唯一身份
- Android：会话实体的创建/更新时间和按 ID 更新逻辑

## 改动

- Rust `SessionRecord.created_at` 改为 Unix 毫秒整数，并新增 `updated_at`。
- 更新已有会话时保留原始 `created_at`，仅刷新 `updated_at`。
- 兼容读取旧版 `YYYY-MM-DD HH:MM:SS` 字符串、秒级整数和毫秒级整数。
- 旧记录缺失 `updated_at` 时用 `created_at` 补齐。
- 后端按 `updated_at` 排序并使用 ID 集合全局去重；前端保留去重兜底。
- 前端日期分组兼容秒/毫秒并正确显示今天、昨天、7 天、30 天和更早。
- 会话 ID 仅允许字母、数字、`-` 和 `_`，拒绝路径穿越。
- 会话消息文件与索引使用临时文件后提交，减少半写 JSON。
- 模型组保存调用参数由错误的 `stateData` 修正为 Tauri 对应的 `modelGroupsState`。

## 测试

- 旧字符串时间迁移为毫秒。
- 秒级和毫秒级数字归一化。
- 非法 session ID/路径穿越拒绝。
- `npm run build` 必须通过。
- GitHub Actions 必须通过 `cargo test --locked` 和完整 Tauri Windows 构建。

## 已知范围

Windows 会话存储仍是 JSON 文件方案，不等同于官方 SQLite/actor 架构；本版本修复数据契约和写入一致性，但后续仍可迁移到事务型数据库。
