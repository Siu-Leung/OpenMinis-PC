# OpenMinis-PC v1.13.0.21 开发日志 (OpenMinis Windows 体验版)

日期：2026-09-05  
范围：Windows 体验版抬头、输入框方案 A 微型小电视、流式输出与图片渲染修复、智能贴底与长按菜单、非系统盘 Minis 自动挂载  
版本：SemVer `1.13.21` / 对外发布 `v1.13.0.21`

## 背景与目标

用户明确授权对 `OpenMinis-PC` 进行核心体验与系统能力全面升级：
1. 抬头定名为 **“OpenMinis Windows 体验版”**，告别测试版标签；
2. 彻底复刻移动端 1:1 的微型小电视（方案 A：输入框浮动监视器 + 状态胶囊条），消除左下角割裂感；
3. 修复流式输入（排除人工延时打字机干扰，接入实时 ReactMarkdown 流式渲染）；
4. 修复对话框图片渲染（解决 URL 百分号编码导致 WSL 沙箱无法找到中文/空格图片的 404 故障）；
5. 还原 Apple HIG 级对话模式（Soul 身份行、垂直细蓝思考导轨、非对称气泡、5 段式 Thinking 滑块、动态停止小方块、Slash 指令）；
6. 智能贴底滚轮（离开底部不抢滚轮，提供 Turn Walk 上跳一轮与回到底部浮动双按钮）；
7. 强化长按/右键上下文菜单（增加 Compact Above 压缩、防误触二次确认）；
8. 外部挂载优先寻找并自动创建非系统盘根目录（如 `D:\Minis`）并挂载至沙箱 `/var/minis/mounts/Minis`，同时支持原生文件夹选择。

## 本次改造详情

### 1. 抬头与版本规范
- 软件窗口与关于页面全面更新为 **“OpenMinis Windows 体验版”**。
- 内部版本升级至 `1.13.21`，对外版本 `v1.13.0.21`。
- 严格同步并校验五处版本源：`package.json`、`package-lock.json`、`Cargo.toml`、`Cargo.lock`、`tauri.conf.json`。
- NSIS 安装机制支持对旧版本平滑覆盖升级。

### 2. 方案 A：微型小电视与浮动工具条合体
- 在 `FloatingToolBar.tsx` 左上角做成经典的 100×65dp 微缩监视器卡片（`ToolPreviewThumbnail`）：
  - `browser_use`：实时展示网页截图预览（支持 `minis://` 协议解析为 Data URL）、迷你地址栏及抓取摘要；
  - `shell_execute`：展示黑底绿字 `$ command`、输出日志流及底部 CPU/MEM 资源 HUD 缎带；
  - `file_*`：展示文件路径与 Diff/代码预览；
- 状态胶囊条右移预留空间，提供运行 Spinner、成功/失败指示、工具标题、浏览器一键接管按钮、多步骤左右切页（`< 1/3 >`）；
- 点击微缩监视器或状态条，平滑弹出全屏 `ToolLiveModal`（标题为经典的 `Minis Computer`，带绿色呼吸灯、支持全屏查看、日志复制、手动接管等）；
- 卸载原先左下角孤立的 `MinisComputer.tsx`。

### 3. 流式输出与对话框图片渲染修复
- **流式输出**：废除前端脱节的 30ms 延迟打字机（避免最后被 `finally` 暴力清空导致整段文字突兀蹦出），收到 `token` 后实时追加；在流式输出区同步接入 `ReactMarkdown`，流式期间实时解析代码高亮、公式和图片。
- **图片渲染**：在 `read_image_data_url` 增加 `url_decode_string`，解决 Agent 输出中文、空格等百分号编码路径时在沙箱中无法匹配的 404 故障；`tool_end` 提取到 `minis://attachments/...` 截图时同步回填至对应 `toolStep.previewImageUrl`。

### 4. 对话模式与聊天框交互还原
- **Soul 身份行**：每轮 Assistant 回复顶部添加 Minis 呼吸图标 + Soul 名字 + 模型名称胶囊 + 时间戳；
- **思考过程**：采用左侧细蓝垂直导轨（`border-l-2 border-[#0A84FF]/60`），微缩等宽字体，带动态计秒；
- **用户气泡**：采用非对称圆角（`rounded-[20px] rounded-br-[4px]`）与暗黑模式板岩蓝纯净层次；
- **聊天框**：
  - 5 段式 Thinking 滑块（`OFF` `LOW` `MED` `HIGH` `MAX`）；
  - 发送按钮生成时平滑转变为红框停止小方块；
  - 斜杠指令支持（输入 `/` 浮现 `/compact`, `/reset`, `/terminal`, `/browser` 快捷面板）。

### 5. 滚轮控制与长按对话管理
- **智能贴底**：离开底部不抢滚轮；离开底部时右下角悬浮 **“跳至上一轮提问 (Turn Walk)”** 与 **“回到底部”** 双按钮；
- **长按/右键菜单**：增加 **“压缩此条以上上下文 (Compact Above)”**，“从此处删除”增加防误触二次确认。

### 6. 非系统盘 Minis 自动挂载
- 启动时自动扫描非系统盘（`D:\`, `E:\`, `F:\`...），若存在则自动在根目录创建 `Minis`（如 `D:\Minis`）并挂载至沙箱 `/var/minis/mounts/Minis`，保护系统盘空间；
- 保留原生文件夹选择对话框，可随时浏览 Windows 任意目录挂载至沙箱。
