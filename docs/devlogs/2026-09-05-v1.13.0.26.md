## 范围

本版本处理两项可独立验证的行为缺口：生成期间消息队列，以及模型组上下文限制的实际执行。实现前对照了官方 Android/iOS 状态模型，没有继续使用仅改变 UI 的占位方案。

- iOS 队列入队与取消：`src/ios/Agent/Chat/AIChatViewModel+Misc.swift`
- iOS 队列消费：`src/ios/Agent/Chat/AIChatViewModel.swift` 中的 `drainQueuedPrompts`

- Android 上下文限制：`ModelGroupDetailScreen.kt` 与 `ChatViewModel.effectiveContextWindowTokens()`

## 改动

### 生成期间消息队列

- 生成期间不再直接拒绝 `handleSend`。
- 输入文字或附件后可加入 FIFO 队列。
- 队列项保留独立的文字和附件快照。
- 输入栏上方展示待处理项和顺序，可取消尚未执行的消息。
- 当前请求完成后，使用后端返回的完整历史作为下一条消息的基础，避免覆盖上一轮回答。
- 首次会话的稳定 session ID 传递到所有排队消息，避免排队过程创建重复会话。
- 生成期间同时保留“加入队列”和“停止当前生成”两个动作。

### 模型组上下文限制

- `AgentConfig` 新增 `context_limit_tokens`。
- `32K`、`64K`、`128K` 转换为实际 token 限制；`不限`保持 `None`。
- 请求发送前保留 system prompt 和最近完整消息，按限制裁剪旧历史。
- 裁剪后移除开头孤立的 tool result，避免生成非法 OpenAI 兼容消息序列。
- 首次发送和右键重试两条路径均应用同一限制。
