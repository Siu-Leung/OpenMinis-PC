# OpenMinis-PC v1.13.0.24 开发日志 (主界面UI重塑、智能标题与全屏右键失焦消除)

日期：2026-09-05  
范围：消灭媒体加载大红框、全局失焦取消右键菜单、侧边栏右键智能总结标题、主界面 Onboarding 极客工作台与居中顶栏重构  
版本：SemVer `1.13.24` / 对外发布 `v1.13.0.24`

## 背景与真实痛点（用户实拍照反馈）

用户通过真机实拍指出 3 个核心严重影响操作手感的问题：
1. **“1 主界面 ui 重构”**：
   - 开屏空会话没有引导，呈现一片死灰死白的大空洞；
   - 媒体未找到或模型未给 URL 时，屏幕中央直接横亘一个巨大的刺眼红色报错框（`无法预览媒体: 百度天气搜索结果`）；
   - 顶栏重心失衡，中间没有当前会话名称；侧边栏标题易截断且无指示轨。
2. **“2 右键对话标题不聪明”**：
   - 侧边栏长按或右键会话项时，直接盖住文字，且标题始终停留在首轮提问（如“打开百度查天气给我截图”），缺少原版一键重新提炼标题能力。
3. **“3 右键对话框这个除了点复制点其他空白地方它不会自动取消”**：
   - 在聊天气泡上右键弹出菜单后，因为全局 `window` 未监听 `setMessageContextMenu(null)`，只要不点复制按钮，点击屏幕任意其他区域（无论左键还是右键）菜单都死死钉在屏幕上，无法关闭。

## 本次重构与深度优化

### 1. 根除大红框报错（优雅降级）
- 修改 `MarkdownImage.tsx`：当 `src` 为空或资源无法加载时，彻底干掉占满半屏的红色报错框；
- 降级为超小巧精致的灰色占位胶囊（`[🖼️ 百度天气搜索结果]`），绝不打断和污染用户正常的对话流体验。

### 2. 全局点击/按键双保险（右键菜单任意空白处即刻取消）
- 在 `App.tsx` 中挂载全局 `window` 监听器：
  - `click` 任意区域：立即清空 `messageContextMenu` 与 `contextMenu`；
  - `contextmenu`（再次右键）：立即清空前一个菜单；
  - `keydown`（按下 ESC 键）：平滑关闭所有上下文菜单；
- 彻底解决用户在气泡右键后“除了复制，点哪里都关不掉”的顽固 Bug。

### 3. 会话标题“聪明化”（✨ 智能总结标题）
- 在侧边栏右键菜单加入 **“✨ 智能总结标题 (Regenerate)”**：
  - 自动从第一轮对话中剔除无用标点与口癖，提纯为 4~8 字短标题（例如将“打开百度查天气给我截图”自动提纯为“🌦️ 百度天气查询”）；
- 右键菜单位置增加 `+8px` 智能避让偏移，靠近屏幕底部时自动贴靠，绝不遮挡用户正在阅读的文字。

### 4. 主界面视觉重构与 Onboarding 工作台
- **Onboarding 工作台**：当新会话或无消息时，居中渲染原版极客工作台：
  - 渐变发光 Logo + 介绍；
  - 4 个直达常用场景的精美卡片（Linux 终端、网页自动化、沙箱文件、记忆知识库），点击自动填入启动提示词；
- **顶栏 1:1 Apple HIG 化**：
  - 居中展示当前会话标题（单行加粗），悬停浮现小铅笔图标，点击随时快速重命名；
  - 左侧常驻沙箱运行就绪绿灯；
  - 右侧收纳模型选择胶囊（带提供商徽章）与操作按钮。
- **侧边栏质感**：
  - 宽度从 256px 优化至 272px，文字展示更充分；
  - 选中会话左侧增加亮蓝色精细指示轨（`border-l-[3px] border-[#0A84FF]`），层级一目了然。
