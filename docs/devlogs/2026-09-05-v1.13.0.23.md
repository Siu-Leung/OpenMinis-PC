# OpenMinis-PC v1.13.0.23 开发日志 (深度灵魂注入、小电视常驻、右键与双Tab记忆)

日期：2026-09-05  
范围：Minis 灵魂准则注入（告别“很傻”的客套）、小电脑常驻与历史会话自动恢复、双Tab记忆管理、Apple HIG 毛玻璃右键菜单与会话克隆/分叉  
版本：SemVer `1.13.23` / 对外发布 `v1.13.0.23`

## 背景与痛点

用户提出极其关键的三点体验反馈：
1. **“还有我没看到小电脑，我不知道什么问题，反正没看到”**：
   - 根因：之前代码在生成结束（`content === "stopped"`）时粗暴执行了 `setToolSteps([])`，导致工具执行完毕的瞬间小电视被秒杀销毁；同时切换到历史会话时未从历史消息解析工具调用，导致历史会话中小电脑不显示。
2. **“聊天窗口的右键和你的区别很大，还有软件主页右键聊天标题也是，整个聊天体验很差”**：
   - 根因：两处右键菜单此前使用了生硬的矩形无遮罩弹窗，且缺失了原版核心能力（分叉新会话 Fork、克隆会话副本 Duplicate、压缩历史上下文 Compact Above、防误触二次确认）。
3. **“还有整个设置里面和你差别很大，电脑端的 MINIS 让人感觉很傻，还有整个界面的 UI 也是差别挺大的，包括但不限于一二级设置里面的”**：
   - 根因：System Prompt 缺失原版 `SOUL.md` 的干练行动信条，模型动辄客套废话而不主动调用工具；二级记忆设置只展示了一段只读死文字，缺乏原版 `GLOBAL.md` 全局长期偏好编辑与每日记忆流检索。

## 本次重构与深度优化

### 1. 消除“很傻”的体验：深度注入 Minis SOUL 哲学
在 `agent.rs` 的系统提示词中全面注入原版 Minis 的行为准则：
- **"Don't perform — help."** 严禁一切无意义的礼貌前缀（“好的”、“很乐意为您服务”），直接调用工具干活；
- **"Have a stance."** 拥有独立见解与审美，不模糊其词；
- **"Act first, ask second."** 能查就查、能跑命令验证就跑命令验证，带着确定答案回来，而不是抛回问题；
- 结构化交代沙箱环境规范、非 ASCII 文件名百分号编码规范、Python matplotlib 绘图规则与后台常驻进程规范。

### 2. 小电脑彻底常驻：任何时候都可见
- **生成结束不销毁**：移除 `stopped` 事件中的 `setToolSteps([])`，工具跑完后小电脑永久定格在最新终端输出或网页画面上，附带状态绿勾；
- **历史会话秒级恢复**：增加 `extractToolStepsFromMessages`，切换到任意历史会话时，自动提取历史工具调用恢复小电脑；
- **未调工具时展示就绪态**：在 `FloatingToolBar.tsx` 中增加待命常驻状态（显示 Alpine Linux WSL2 状态与 CPU 缎带），点击随时唤起 Minis Computer。

### 3. 两处右键菜单全面升级为 Apple HIG 毛玻璃浮窗
- **消息右键菜单（Message Context Menu）**：
  - 增加背景淡入磨砂遮罩，点击任意空白处平滑关闭；
  - 补充 **“从此处分叉新会话 (Fork Session)”**：截取当前问题及之前所有历史，一键生成独立新会话探索不同推理分支；
  - 补充 **“编辑此问题 (Edit Question)”**：内容填回输入框光标自动聚焦；
  - 补充 **“压缩此条以上历史 (Compact Above)”**；
  - 补充 **“从此处截断删除”**（红色高亮 + 二次防手滑确认）。
- **侧边栏会话行右键菜单（Session Context Menu）**：
  - 增加背景点击遮罩；
  - 补充 **“克隆会话副本 (Duplicate)”**：后端新增 `duplicate_session`，一键克隆当前会话及其完整历史消息；
  - 包含置顶/取消置顶、重命名标题、压缩上下文、导出 Markdown 以及删除会话（带确认）。

### 4. 记忆系统（Memory）1:1 升级为原版双 Tab 控制台
- **Tab 1：全局长期偏好记忆 (GLOBAL.md)**：
  - 支持直接在客户端编辑跨会话固定的规则、习惯与项目背景，一键保存至沙箱 `/var/minis/memory/GLOBAL.md`，并在每次启动时自动注入模型上下文；
  - 支持清空、字符数统计与保存 Toast 提示。
- **Tab 2：今日执行记忆流水 (/var/minis/memory/YYYY-MM-DD.md)**：
  - 展示 Agent 自动归档的重要事实与运行结论，支持滚动阅读。
