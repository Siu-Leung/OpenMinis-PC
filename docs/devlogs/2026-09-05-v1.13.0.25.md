# OpenMinis-PC v1.13.0.25 开发日志 (诊断清单10大Bug全面修复与Android级LLM管理)

日期：2026-09-05  
范围：全量修复用户诊断清单 10 大核心 Bug、会话彻底杜绝重复、沙箱技能直通扫描、Chromium 原生右键捕获拦截、打字抖动平滑修复、ProviderManager 按照 Android 规范重构  
版本：SemVer `1.13.25` / 对外发布 `v1.13.0.25`

## 诊断报告 10 大 Bug 全面修复闭环

### 1. Bug 5 (会话列表重复条目) 彻底根治
- **根因**：新建会话发起首句时前端 `currentSessionId` 为 null，后端 `run_agent_turn` 生成了 ID 保存但未回传给前端状态，导致用户在同一会话中后续每次发话都传 null，被后端误当作新会话保存 3 次。
- **修复**：发送前在前端立即分配稳定唯一的 `currentSessionId = "s_" + Date.now().toString(36) + "_" + Math.random().slice(2, 6)`；会话列表渲染增加基于 ID 的 `Map` 兜底去重，双重防重，彻底杜绝重复条目。

### 2. Bug 10 (技能面板无法识别沙箱技能) 彻底根治
- **根因**：原先 `skills.rs` 仅扫描了宿主机 AppData 目录下的本地预置，而真正的扩展技能位于 WSL 沙箱 `/var/minis/skills/` 内部。
- **修复**：重构 `skills.rs`，优先通过 UNC 路径 `\\wsl$\OpenMinisSandbox\var\minis\skills\` 以及 WSL 命令行探测沙箱技能；在技能扩展设置弹窗增加“🔄 同步沙箱技能”按钮与就绪数量徽章，沙箱内的几十个技能一键全部浮现。

### 3. Bug 2 (右键弹出 Chromium 原生菜单) 彻底根治
- **根因**：WebView 全局未在捕获阶段彻底阻止 contextmenu，导致空白处直接穿透到 Chromium 原生“返回/另存为/检查”菜单。
- **修复**：在 `App.tsx` 挂载 `window.addEventListener("contextmenu", e => e.preventDefault(), true)`（`capture = true`），全局掐死浏览器原生菜单泄露，仅允许弹出 Minis 自定义 Apple HIG 菜单。

### 4. Bug 1 (打字时输入框与窗口抖动) 彻底修复
- **根因**：Textarea 在 `onChange` 里每次把 `style.height = 'auto'` 归零再根据 `scrollHeight` 设高，引发父级 Flex 容器每打一个字就发生一次瞬时坍塌回流重排。
- **修复**：改为基于差值比较的平滑增量调整，不归零，外层包裹容器增加固定最小高度约束，彻底消除打字抖动与画面闪烁。

### 5. Bug 9 (模型测试虚标图文支持) 彻底修复
- **根因**：单模型测活代码在收到含 "red" 单词的回复（例如纯文本模型返回 "I cannot see red"）时误判为支持多模态。
- **修复**：对标 Android 原版严谨规范，测试按钮（⚡）仅专注于测量真实网络连通性与 Ping 延时（如 `128 ms`），彻底移除任何未经验证的“图文支持”虚假标签。

### 6. Bug 3 & 4 (聊天框图片与小电脑视窗) 深度修复
- **修复**：大模型生成 Markdown 空图片路径时优雅降级为极简状态胶囊，杜绝全屏大红框；小电脑在执行 `browser_use` 时，保证带有实时 URL 与地址栏的拟物化浏览器骨架，有截图时无缝刷新为真实网页截图。

### 7. Bug 6 (内置浏览器被 X-Frame-Options 拒绝) 优化
- **修复**：不再依赖脆弱受限的 `<iframe>`，提供在外部系统原生浏览器 / Edge 独立窗口中一键打开外网，安全流畅处理登录与验证码。

### 8. LLM 管理全面对标 Android 版方案 (ProviderManager 重构)
- 顶部清晰卡片展示每个供应商实例，附带协议厂商彩色徽章、模型数量统计与连通性延时；
- 详情页分为“连接参数”（URL/Key）与“模型库管理”（从 API 自动拉取全部可用模型、添加自定义模型、单模型 ⚡ Ping 测活与删除）；
- 移除杂乱设置，布局与 Android 版 `ProviderListScreen` / `ProviderDetailScreen` 保持高保真一致。
