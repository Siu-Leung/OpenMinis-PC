# OpenMinis-PC v1.13.0.30 开发日志

日期：2026-09-06  
内部版本：`1.13.30`  
对外版本：`v1.13.0.30`  
产品：OpenMinis Windows 体验版

## 范围

根据实际工具日志修复 `browser_use`/`shell_execute` 的 URL 参数污染，并限制 Edge 与 WSL 截图落地链路的等待时间，避免一次截图阻塞 Agent 数分钟。

## 现场证据

- `browser_use screenshot` 于 01:02:53 开始，下一工具直到 01:05:59 才执行，间隔约 186 秒。
- 工具参数和 shell 命令多次包含 `@url:\`https://...\``。
- 后续较短调用说明目标网页可以访问，问题不只是网站 iframe 限制。

## 改动

- `sanitize_tool_args` 从仅清理字符串外层包装改为扫描整段字符串，支持 shell/Python 命令内部多个 `@url:\`...\`` 标注。
- 工具日志改为记录实际派发的清洗后参数，避免日志与真实执行参数不一致。
- 为内嵌 URL 清洗增加 Rust 回归测试。
- Edge `navigate/get_text/screenshot` 子进程启用 `kill_on_drop`，超时后回收进程。
- 截图日志记录 Edge 阶段和沙箱写入阶段耗时。
- 沙箱二进制写入移除可能长期阻塞的 `\\wsl$` 同步 UNC 首选路径，统一使用可终止的 WSL stdin 管道。
- 截图写入沙箱增加 12 秒硬超时；失败明确返回，不假报截图成功。

## 验证

- `npm run build` 必须通过。
- GitHub Actions 必须通过 `cargo test --locked` 和完整 Tauri Windows 构建。
- Release 必须包含 setup EXE、MSI 和便携 EXE 三个资产。

## 已知范围

本版本修复 screenshot 卡顿和 URL 参数污染，不将 iframe 替换或持久浏览器 WebView/tab pool 声称为完成；主流网站禁止 iframe 的结构性问题仍需独立浏览器 WebView 方案。
