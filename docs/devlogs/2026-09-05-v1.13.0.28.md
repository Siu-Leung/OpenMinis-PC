# OpenMinis-PC v1.13.0.28 开发日志

日期：2026-09-05  
内部版本：`1.13.28`  
对外版本：`v1.13.0.28`  
产品：OpenMinis Windows 体验版

## 范围

改进工具预览状态的一致性和截图刷新时机，为后续完整 ToolSnapshot/持久浏览器实现建立稳定事件协议。

## 官方参考

- iOS：`AssistantBlock.toolUseId`、`ToolSnapshotItem`、`ToolLiveSheet`
- Android：`AssistantBlock.id`、`ToolPreviewThumbnail`、`rememberBrowserLiveSnapshot`
- 官方原则：工具状态和快照按稳定 tool call ID 绑定，不能依赖“最后一个 running 项”。

## 改动

- `tool_start` 和 `tool_end` 事件增加稳定 `call_id`。
- 前端工具步骤直接使用后端 call ID 作为唯一键。
- 工具结束时优先按 call ID 精确更新对应 block，旧事件才回退到最近 running block。
- browser screenshot 成功后发出独立 `tool_snapshot` 事件。
- FloatingToolBar 收到 snapshot 后立即刷新对应缩略图，不等待整轮 Agent 结束。
- 移除伪造的固定 CPU/MEM 数字；没有真实资源采样时仅显示 RUNNING/READY 和真实工具状态。

## 验证

- `npm run build`：通过。
- GitHub Actions 必须通过 `cargo test --locked` 和完整 Tauri Windows 构建。
- 五处内部版本必须一致为 `1.13.28`。

## 已知范围

本版本只解决稳定映射和截图即时刷新。Windows 后端仍是一次性 Edge headless 进程，尚未具备官方移动端持久 WebView tab pool 的连续实时帧；开发日志不将本版本描述为完整 1:1 实时浏览器。
