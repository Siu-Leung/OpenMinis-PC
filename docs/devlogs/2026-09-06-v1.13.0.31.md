# OpenMinis-PC v1.13.0.31 开发日志

日期：2026-09-06
内部版本：`1.13.31`
对外版本：`v1.13.0.31`
产品：OpenMinis Windows 体验版

## 范围

根据两份架构蓝图对 `v1.13.0.30` 进行实证审计，先处理最高风险的本地凭据明文存储，并建立可信的长期进化报告。

## 改动

- 新增 `docs/OPENMINIS_PC_EVOLUTION_REPORT.md`，逐项裁决两份蓝图并按当前代码重排路线。
- 新增版本化 secret envelope，Provider 与环境变量不再以明文 JSON 落盘。
- Windows 使用当前用户 DPAPI (`CryptProtectData` / `CryptUnprotectData`) 保护静态凭据。
- 读取旧 `providers.json` / `env_vars.json` 明文数据后自动迁移为 DPAPI envelope。
- 使用 Windows `MoveFileExW` 的 replace + write-through 语义提交加密文件。
- 前端不再把 Provider/API Key 写回 WebView localStorage；旧缓存迁移成功后删除。
- 环境变量名限制为 `[A-Za-z_][A-Za-z0-9_]*`，拒绝 shell 控制语法。
- README 将 MCP、Edge 浏览器、定时任务、性能数字和 UI 对齐描述改为当前可验证事实。

## 测试

- 加密 envelope 不包含明文且可往返解码。
- 旧明文 JSON 可识别并标记迁移。
- 未知 envelope 版本被拒绝。
- Windows CI 实际运行 DPAPI current-user round-trip。
- 注入型环境变量名被拒绝。
- `npm run build` 必须通过。
- GitHub Actions 必须通过 `cargo test --locked` 和完整 Tauri Windows 构建。

## 已知范围

- DPAPI 密文绑定当前 Windows 用户，不支持跨用户或跨机器直接恢复。
- 现有备份模块的 providers/env/password/encrypted 选项尚未真正实现；本版本没有声称凭据可跨机器备份。
- CSP、Tauri capabilities、剪贴板/Provider 写入确认制和完整 MCP 协议栈属于后续 P0/P1 切片。
